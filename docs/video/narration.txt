## 1 af_heart
Most small web apps need the same dull parts before they do anything useful.

A login. A place to keep secrets. A safe way to talk to the database.

...

In this video we build a small app called Notes. We build it on agentpg-kit, the shared library behind every app in the AgentPG ecosystem.

And we get all of that without writing it.

## 2 af_heart
The kit is a library, not a server. It is a handful of small blocks.

Let's look at them.

First, the vault. It encrypts stored secrets.

Next, auth. One front door for every kind of caller. It accepts an admin password, an API token, or a token from a company identity provider.

There is also a security middleware.

And a shared browser interface. It is served from a path called slash kit.

The apps in this ecosystem are built from these same blocks. TrustDesk, PagerLens, and PayBroker are examples.

## 4 am_michael
This is the whole security model of the app.

First, roles. An admin can do everything. An editor can read and write notes. A viewer can only read.

...

Next, the vault line. That gives us encrypted storage.

The line after it turns on single sign-on, but only if an identity provider address is set.

Then local login. And one authenticator, which is the front door.

Now the database. It needs one table. The kit runs this migration once, on start.

Last, a route. The delete route names the permission it needs.

Notice that the code never asks who you are. It asks one question. Can this caller write notes?

The kit answers that for every kind of credential.

Now, access for programs. Programs need to reach the app without a browser. So the app can create API tokens.

Now we use it to read the notes.

[pause 1.5]

[pause 1.5]

[pause 1.5]

Now we reload the browser.

The screen says the keys are locked. The encryption key only lives in memory. So after a restart, the vault is locked.

Type the admin password, and it opens again.

[pause 2.0]

Now the better way. Give the server a platform key.

[pause 2.5]

That is a secret your deployment platform stores.

[pause 1.0]

From now on, restarts need no one.
